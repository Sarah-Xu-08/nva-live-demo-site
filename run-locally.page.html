Run the research application locally.

The online demo replays saved trials, EEG signals and prediction results. To record EEG, run a decoder, edit trials or adapt the application to your equipment, install the full application on your computer or server.

The research repository is currently private. Source downloads require repository access.

Start with Docker

Install Docker, download the source and open a terminal in its folder. Build the image using the included Dockerfile:

docker build -t nva-live-demo .
docker run --rm -p 127.0.0.1:65008:65008 \
  -v nva-recordings:/app/live_demo/runtime_data \
  -v nva-trials:/app/live_demo/trials \
  -v nva-trial-history:/app/live_demo/trial_history \
  nva-live-demo

Open localhost:65008. Named volumes retain recordings, trial edits and revision backups between container runs. This is a local research service; keep it on your own computer or trusted network.

The source download includes the application and authored trials. Participant recordings, trained model bundles and saved analysis archives are separate inputs; they are not bundled into the Docker image. Without those inputs, prerecorded Playing reports unavailable. Trial Editor and mock recording can be used without them.

Connect an EEG device

The application receives compatible EEG through Lab Streaming Layer (LSL). Start your device's LSL outlet and configure the stream's channel names and sampling rate. The built-in Playing pipeline expects the documented 14-channel, 128 Hz input.

Docker networking needs explicit configuration for LSL discovery. On Linux, host networking is an option. On macOS or Windows, installing Python directly on the acquisition computer is the simplest starting point; container networking must be verified with your device.

Use your model

Model integration is done in the local Python application. Use its decoder manifest and adapter interfaces, matching preprocessing, channels, sampling rate and output labels. The current Playing pipeline uses its saved causal model bundles; replacing it with a different architecture requires an adapter. Uploading arbitrary weights does not automatically make them compatible.
