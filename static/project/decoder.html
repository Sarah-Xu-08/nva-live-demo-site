Replay decoding: available with the complete EEG and warm-up assumed here, including positions excluded from training.

Background before the event

Start at gameplay +0.25 s; stop before C −0.125 s or the first PE/unresolved action, whichever is earlier. Small gaps avoid the immediate gameplay and critical boundaries.

An early critical response

Ends from C +0.5 s to before C +1 s include 0.5–1 s of post-event EEG. Stop earlier at a different PE type, an unresolved action or trial end.

Leave ambiguous periods unlabeled

For a nonPE critical action, add ends from C +0.5 s only while no PE/unresolved action has occurred. Other ends are excluded from training; replay still predicts throughout gameplay.

At most eight evenly spaced epochs per eligible interval enter the fitting pool, followed by class balancing. Missing data and filter warm-up are excluded. Every label interval stops by trial end.

Training choices, not biological boundaries. Early background windows and their baselines can include fixation. PE training keeps the 0.5–1 s response interval, while demo validity now checks predictions through trial end.

Then choose a label. The winner needs a lead of at least 10 percentage points; otherwise the label is “Uncertain.” This rule does not change the probabilities. Missing neural signals or incomplete warm-up is “Unavailable.”

PRE-RECORDED NEURAL SIGNALS

One source-session model.

Rebuild causal filter state from the recording’s prefix, then recompute from raw neural signals using that source session’s saved model. Replay speed changes presentation time, not model inputs.

REAL-TIME NEURAL SIGNALS

Five model vectors.

Compute one feature vector and average the five saved session-model probability vectors equally. Acquisition gaps and reconnects restart filter warm-up.

How to read the live output +
Three mutually exclusive classes

The model outputs nonPE, SPE-only and RPE+SPE. On the current demo, the blue “RPE” trace displays P(RPE+SPE), and the pink “SPE” trace displays P(SPE-only). They are class probabilities, not two independent binary heads.

Observational decoding

Critical labels, game events and trial identities do not enter the inference module. The decoder does not choose actions; visible corrections follow the stored trial script. The 1.5-second display window is separate from the 1-second feature window.
