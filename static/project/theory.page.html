At time t, st is the shared state, including task context and relevant history; atH and atAI are the human and AI actions. The environment’s transition model T maps the current state and joint action to the observed next state st+1.

We then evaluate this observed transition against the human’s expectations. gtAI|H denotes the goal expected of the AI by the human. The human reward function RH evaluates the AI’s contribution relative to that expected goal. Each action is evaluated against the human’s expectations at that time. The reward check below assesses goal compatibility; the state check assesses acceptable execution.

RPE · Task mismatch

RPEt=rt+1AI−rt+1AI|H

RPE compares the reward the AI achieved in the team, rt+1AI, with the reward the human expected

rt+1AI|H=RH(st,atH,atAI,st+1;gtAI|H)∈ℝ.

SPE · Execution mismatch

SPEt=minz∈ℰtAI|Hd(φ(st+1),z)

SPE compares the next-state features φ(st+1), with the accepted set

ℰtAI|H={φ(T(st,atH,a)):a∈𝒜tAI|H},

using the distance to the nearest accepted representation.

The superscript AI|H means human prediction of the AI. Reward evaluates goal compatibility; the accepted-action set specifies acceptable execution.

Why state features are different from reward +

Reward evaluates task compatibility

A scalar reward evaluates how well the contribution supports the expected task. Approaching a handoff counter can remain goal-compatible even when the chosen approach unnecessarily blocks the human.

State features retain execution details

φ(st+1) describes what happened: positions, objects, document structure, or other specified features. Keeping only the reward would discard execution differences. RPE and SPE can use overlapping evidence and can both be nonzero; separate checks do not imply statistical independence.

LLM DOCUMENT COLLABORATION · PROPOSED APPLICATIONSummarize Article A in three bullets with citations.

State and task
The shared draft, instructions and conversation form the state. An AI action is a response, edit or tool call; T updates the shared document. Faithfully summarizing the article satisfies the goal. Asking for genuinely missing source text can be valid preparation.

Execution and errors
A faithful summary in the expected format can satisfy both expectations. Unrequested prose can preserve the goal reward while producing an execution distance. Translating instead of summarizing can change both the goal reward and the next-state representation. φ retains structure, citation preservation and document changes; a validated semantic evaluator or explicit annotation rules replaces exact kitchen-state matching.

In this simplified GridWorld setting, only the AI takes actions in the environment. The human monitors the AI without taking actions. The human has one strict preference: a specified goal and a single expected trajectory for reaching it.

rt+1AI|H=RH(st,atH,atAI,st+1;gtAI|H)∈ℝ.
