# Latin Modern Math

Unmodified WOFF2 distribution of Latin Modern Math, served locally so equations
do not depend on a third-party font service. The OpenType MATH table supplies
script positioning, operator sizing and fraction spacing to native MathML.

- Font project: https://www.gust.org.pl/projects/e-foundry/lm-math
- Webfont source: https://github.com/fred-wang/MathFonts/tree/9182b146cb64ac1a5e9cb92a09cd79612ca95d1c/LatinModern
